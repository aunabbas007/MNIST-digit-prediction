# MNIST Digit Prediction — PyTorch CNN

A convolutional neural network project for classifying handwritten digit images from the MNIST dataset.

## Repository contents
- `notebook.ipynb` — model training and experimentation notebook.
- `mnist_cnn_model.pth` — saved model weights.
- `requirements.txt` — Python dependencies.

## Workflow
1. Load and prepare MNIST image data.
2. Train a CNN using PyTorch.
3. Evaluate digit-classification performance.
4. Save model weights for later inference.

## Run
Install dependencies:
```bash
pip install -r requirements.txt
```

Open `notebook.ipynb` in Jupyter or Google Colab and execute the cells in order.

## Stack
Python · PyTorch · Torchvision · Jupyter

## Learning focus
Image tensors, convolutional neural networks, training loops, loss optimization, and model checkpointing.
